# Q6: The double slit as a two-state system


## The question

Setting aside the mechanics of how qubits encode the double slit in a circuit: Can 
we describe the double-slit experiment in terms of a two-state basis system? That is, 
does the abstract $\mathbb{C}^2$ framework — two basis vectors, complex scalars, 
interference via relative phase — apply directly to the physics of one photon 
encountering two slits?


## Context: the simplest quantum system

In quantum mechanics we have an $n$-dimensional vector space with an inner product 
(a Hilbert space) used to describe the state of an $n$-dimensional quantum system. 
For a continuum of states $n$ can be infinite. For finite systems $n$ might be 832 or 
19 or 5, but in the simplest case $n$ must be no less than 2. The spin of a fermion 
is such a 2-dimensional system.

The vector space is over the complex field $\mathbb{C}$ (required for interference). 
Any state of this simplest system is:

$$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle, \quad \alpha, \beta \in \mathbb{C}, \quad |\alpha|^2 + |\beta|^2 = 1$$

The two complex scalars are linked in amplitude (normalization: one degree of freedom) 
and connected by a relative phase (second degree of freedom). A third degree of 
freedom — the global phase — is mathematically real but physically meaningless and 
therefore ignored. So $\mathbb{C}^2$ provides exactly two physical degrees of freedom 
for a two-state system.


## Answer: yes, with a caveat

Yes — the double-slit experiment *can* be described as a two-state system, and this 
description captures the essential interference phenomenon. But it does not capture 
*where* on the screen the photon lands. The full experiment requires a larger Hilbert 
space.

### The two-state ("which path") description

Before the photon reaches the screen, its path degree of freedom can be modeled as:

$$|\psi_{\text{path}}\rangle = \alpha|A\rangle + \beta|B\rangle$$

where $|A\rangle$ = "photon went through slit A" and $|B\rangle$ = "photon went 
through slit B." This is $\mathbb{C}^2$ exactly as described above.

If we prepare the photon with no which-path bias:

$$|\psi_{\text{path}}\rangle = \frac{1}{\sqrt{2}}(|A\rangle + |B\rangle)$$

This is the state $|+\rangle$ — equal superposition, relative phase zero. The photon 
has no definite path. The relative phase between the two amplitudes is what will 
produce interference downstream.

### Where the extra structure comes from

The two-state model tells us *that* interference occurs (the relative phase between 
paths is physically meaningful) but not *where* on the screen it manifests. To get the 
spatial fringe pattern, we need to include the position degree of freedom:

$$|\psi\rangle = |A\rangle \otimes |\psi_A(x)\rangle + |B\rangle \otimes |\psi_B(x)\rangle$$

Here $|\psi_A(x)\rangle$ and $|\psi_B(x)\rangle$ are the position-space wave functions 
for light arriving from slit A and slit B respectively. They differ by a 
position-dependent phase:

$$\psi_B(x) = e^{i \cdot 2\pi d x / (\lambda L)} \cdot \psi_A(x)$$

When we don't observe which path (trace out the path degree of freedom), the two 
amplitudes add coherently at each screen position:

$$\psi_{\text{screen}}(x) \propto \psi_A(x) + e^{i \cdot 2\pi d x / (\lambda L)} \psi_A(x) = \psi_A(x)\left(1 + e^{i\phi(x)}\right)$$

The intensity is:

$$I(x) \propto |1 + e^{i\phi(x)}|^2 = 4\cos^2\left(\frac{\phi(x)}{2}\right) = 4\cos^2\left(\frac{\pi d x}{\lambda L}\right)$$

This is the fringe pattern — generated by the relative phase between the two paths 
varying as a function of screen position.


### The connection to $\mathbb{C}^2$

The two-state system is doing the heavy lifting at each screen position independently:

At position $x$, the photon's state in the path basis is effectively:

$$|\psi(x)\rangle = \frac{1}{\sqrt{2}}\left(|A\rangle + e^{i\phi(x)}|B\rangle\right)$$

This is a qubit state on the Bloch sphere's equator with azimuthal angle $\phi(x)$. 
As $x$ varies across the screen, $\phi(x)$ sweeps through values $0, \pi, 2\pi, \ldots$ 
producing constructive and destructive interference in alternation.

So the fringe pattern is literally the Bloch equator mapped to a spatial coordinate: 
each screen position corresponds to a different azimuthal angle, and the probability 
of detection oscillates as $\cos^2(\phi/2)$.


### Summary

| Aspect | Two-state ($\mathbb{C}^2$) | Full double-slit |
|--------|---------------------------|-----------------|
| Basis vectors | $\|A\rangle$, $\|B\rangle$ (which slit) | $\|A\rangle\|x\rangle$, $\|B\rangle\|x\rangle$ (path $\otimes$ position) |
| Relative phase | Single value $\phi$ | Position-dependent $\phi(x) = 2\pi dx/(\lambda L)$ |
| Interference | Yes/no (one probability) | Fringe pattern (probability varies with $x$) |
| Hilbert space dimension | 2 | 2 $\times$ (continuous position) |

The $\mathbb{C}^2$ structure is the *engine* of the interference. The spatial fringe 
pattern is what you get when you let the relative phase vary continuously across a 
family of $\mathbb{C}^2$ problems parameterized by screen position.


### The which-path connection

This also clarifies why "observing which slit" destroys the pattern: if you measure 
the path qubit (project onto $|A\rangle$ or $|B\rangle$), the relative phase becomes 
irrelevant — you've collapsed to one definite path. Each path alone produces no 
fringes (just the sinc envelope from single-slit diffraction). The interference term 
$\cos^2$ requires both amplitudes to be present and coherent — i.e., the path qubit 
must remain in superposition.

This is the same physics as: measuring a qubit in the Z-basis destroys X-basis 
information. Measuring "which slit" is a Z-measurement on the path qubit; the 
interference pattern lives in the X-basis (relative phase) information.


### Equivalent two-path interferometers

The double-slit experiment at a single screen position is one instance of a general
two-path interferometer. All of the following share the same H-P-H circuit structure
(superpose $\to$ accumulate relative phase $\to$ interfere $\to$ measure):

| System | $|0\rangle$ / $|1\rangle$ | Phase source | Output |
|--------|--------------------------|--------------|--------|
| Double slit (per position) | path A / path B | path-length difference at screen position $x$ | detection probability at $x$ |
| Mach-Zehnder interferometer | upper arm / lower arm | phase shifter in one arm | which detector clicks |
| Spin-1/2 in rotating B field | spin-up / spin-down | Larmor precession angle | spin measurement outcome |
| Photon polarization through wave plates | H / V | birefringent phase retardation | polarization measurement |
| Ramsey interferometry (atomic clock) | ground / excited state | free precession between pulses | transition probability |

In every case the physics is: create a coherent superposition of two states, let a
relative phase accumulate, then recombine and measure. The DSE scans the phase across
spatial positions to build a fringe pattern; the Mach-Zehnder holds one fixed phase;
Ramsey interferometry scans time. Same circuit, different physical encoding.
